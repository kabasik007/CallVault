# Тестовий APK Zilla Recorder DEV (Android 12+)

Це окремий тестовий Android-додаток, пакет `com.baba.callvault.zilla`.
Його можна встановити без заміни офіційного `com.baba.callvault`.
Водночас для діагностики аудіо краще тестувати тільки один рекордер
за раз: дві програми можуть конкурувати за один системний аудіопотік.

1. Перейди на https://github.com/kabasik007/CallVault/actions
2. Якщо GitHub пропонує кнопку **Enable workflows**, увімкни GitHub Actions
   для свого форка. Інакше збірка не запуститься.
3. Вибери **Zilla Recorder - Android test APK**.
4. Після успішного запуску відкрий його та знайди секцію **Artifacts**.
5. Завантаж `Zilla-Recorder-DEV-apk`, розпакуй ZIP.
6. Установи `app-debug.apk` на Android 12 або новішу версію.

### Важливо
- Це підписаний debug APK, не фінальна release-версія.
- Новий CI запуск може створити інший ключ підпису. Тоді оновлення поверх
  попереднього APK не встановиться. Видалення застосунку видалить локальні
  дані, тому важливі записи тримай в окремій перевіреній копії.
- Режим запису без Wi-Fi відкриває класичний ADB TCP-порт: не вмикай його
  до перевірки безпеки своєї мережі.
- Спочатку протестуй звичайний дзвінок та запис обох голосів.
  Telegram / WhatsApp / Viber перевір окремо — VoIP залежить від прошивки.
- Google Drive краще ввімкнути в режимі «локально + хмара».
- AI-розшифрування та підсумки **не обов'язкові**. Можна нічого не
  завантажувати й використовувати застосунок виключно для запису.
